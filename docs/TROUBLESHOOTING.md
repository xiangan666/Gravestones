# 常见问题与排查

先在世界副本排查。反馈时记录游戏版本、模组版本、平台、墓碑编号、状态、目标维度、是否搬动过、重现步骤和内容日志；不需要上传完整私人存档。

| 症状 | 依据与检查 | 处理 |
| --- | --- | --- |
| 远距离钥匙传送失败 | 查看是否提示目标区块未加载、区域配额不足或墓碑实体加载超时；方块可读不代表实体已就绪 | 确认两包版本一致、命令可用，预留常加载区域；等待完成且持续手持原钥匙。2.0.13起会在方块就绪后再等待实体最多80tick |
| 传送提示墓碑已移动 | 核对是否挖起过，即使重新放回原坐标也属于移动 | 搬运后的墓碑永久失去传送资格，使用寻墓器前往；补领钥匙不会恢复资格 |
| 传送提示实体加载超时或编号冲突 | 目标方块已可读但对应显示实体缺失、未恢复，或附近有多个同编号候选 | 保留钥匙和记录，稍后重试并提供编号与日志；不要手工生成同编号实体或清除记录 |
| 保险库区块已加载却找不到库存 | 原生库存实体ID失效时会按编号重连并等待；确实删除后无法从统计信息恢复完整物品 | 查看旧版本内容日志是否存在 `damage_sensor` 解析错误和窒息死亡；库存已损失时恢复损失前世界备份 |
| 背包满，墓碑没有结束 | 剩余物品仍在墓碑库存中；经验已经结算时不会重复发放 | 腾出空间，继续使用同编号钥匙领取，全部领完才消耗本次钥匙 |
| 内容日志出现组件或脚本依赖错误 | 检查基岩最低版本、行为/资源包版本是否匹配、是否同时启用旧包 | 同时替换两包；本模组不需要 Beta API。稳定API 2.0没有 `Block.isSolid` |
| 从源码运行校验找不到模块 | 检查 Node.js、npm、Python 及依赖是否安装 | 在项目根目录执行下面的 PowerShell 命令；使用锁文件安装，不手动修改依赖版本 |
| Release停在草稿或工作流失败 | 先看 GitHub Actions 对应标签日志和资产核对结果；存在草稿不代表发布完成 | 修复具体失败后，用发布工作流的手动入口继续同一标签；已正式发布的内容需要新版本 |

```powershell
node --version
npm --version
python --version
npm ci
npm run check
npm test
npm run build
npm run build:verify
```
