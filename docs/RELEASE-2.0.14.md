# 墓碑模组 2.0.14

本版本完善从源码验证到正式下载的工程流程。沿用2.0.13的墓碑、钥匙、库存与远距离传送行为，既有包UUID、编号及动态属性格式保持兼容。

## 变化

- `package.json`作为版本事实源，使用独立同步命令更新两包、模块、锁文件和脚本常量，无需重新生成图片或实体。
- 安装包继续使用标准名称，新增配套SHA-256文件；包内附安装与原作归属说明，构建后逐项比对源码。
- 源码校验不再依赖未提交的原始2.0.8归档，新增文档链接检查及版本/构建回归。
- CI在Windows与Linux执行锁定安装、类型/资源/链接检查、测试、构建及产物核对；Actions固定到已核实的完整提交SHA。
- 发布流程核对远程标签和提交，上传草稿资产并下载核验后正式发布；可恢复中断，发布后再次验证资产。
- 保持依赖版本和完整性摘要，下载地址统一到官方npm注册表。
- 补齐安装、排查、贡献、维护、版本与发布文档，保留原作者及历史译者记录。

## 安装与升级

下载 `Gravestones-lanshiyi-v2.0.14.mcaddon` 和 `Gravestones-lanshiyi-v2.0.14.mcaddon.sha256`，核对摘要后导入。最低基岩引擎1.21.90，稳定Script API 2.0.0；需要命令权限与常加载区域配额，模组维护 `keepInventory=true`。先备份世界，同时替换行为包和资源包。具体步骤见[安装指南](INSTALL.md)。

SHA-256用于检查下载内容一致性，不是发布者身份签名。安装包包含行为包、资源包、`INSTALL.md`和`NOTICE.md`，不包含本地测试世界、依赖缓存或原始归档。
