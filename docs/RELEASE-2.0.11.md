# 墓碑模组 2.0.11 · 库存实体与附近传送修复

原作 **Effect99**。汉化与二改 **lanshiyi**，联系 **3199912548@qq.com**。

## 本版修复

- 在官方基岩版服务端复现“保险库已加载，但找不到库存”：旧实体的伤害组件使用了引擎不接受的布尔值，库存和锚点在基岩中窒息死亡。现使用有效的字符串枚举，全伤害保护覆盖窒息；浮力参数也修正到有效范围。
- 修复传送读取不存在的`Block.isSolid`属性。安全地面改用原生碰撞检测，支持草丛、向下落点、水平32格/上下32格搜索。
- 附近没有天然安全点时，在空旷处搭建3×3圆石落脚台，成功后保留；确认菜单会说明。失败退款、恢复次数和本次平台改动；不强行传入岩浆或实心方块。
- 构建新版本保留已有旧包、校验文件及其他资料。每个版本仍然只有一个合并行为包与资源包的安装包。

## 安装与升级

导入`Gravestones-lanshiyi-v2.0.11.mcaddon`，在世界设置启用2.0.11行为包和资源包；保留原包UUID，沿用2.0.9/2.0.10的编号和钥匙。使用稳定Script API 2.0.0，不要求Beta API。目标最低引擎1.21.90，常加载区域仍需要命令权限与配额。

**先备份世界。** 已经在旧版本中死亡/被删除的库存无法由新安装包凭空恢复，需要出问题之前的世界备份。仍存在的库存继续按原编号读取；缺失时保留墓碑和经验记录，不用空库存伪报成功。
