# 墓碑模组安装与升级

适用于 Minecraft 基岩版，最低引擎1.21.90；模组使用稳定 `@minecraft/server 2.0.0` 与 `@minecraft/server-ui 2.0.0`。

## 安装

1. 从项目 GitHub Releases 下载同一版本的 `Gravestones-lanshiyi-v<版本>.mcaddon` 与 `.mcaddon.sha256`。
2. 使用 SHA-256 核对安装包。校验文件第一列是摘要，第二列是安装包文件名。
3. 打开 `.mcaddon` 导入游戏，在世界设置中同时启用同版本的行为包和资源包。
4. 允许命令/作弊，预留常加载区域配额；模组会维护 `keepInventory=true` 并接管死亡遗物。
5. 在测试世界放入少量物品并死亡；复活后检查绑定钥匙、墓碑编号和遗物领取。正式存档验收前先备份。

普通绑定钥匙在全部遗物领取后消耗；满背包未领完时保留。钥匙传送需要1颗末影珍珠，每把钥匙一次，只能前往从未搬动的原位置墓碑。未加载目标会等待，失败不扣珍珠和次数。

## 升级与恢复

先备份世界，导入新版本并替换旧行为包、资源包，避免同时启用两套脚本。包UUID和既有墓碑编号保持不变；墓碑、钥匙、库存和已用传送令牌沿用原数据。每次升级后在存档副本测试死亡、领取和传送。

不要与其他接管死亡背包的模组同时使用。已经在旧版本中被删除或死亡的原生库存实体无法由升级重建；应使用发生损失之前的世界备份。降级安装包不能保证撤回存档数据变化，完整恢复需要同时恢复对应世界备份。
