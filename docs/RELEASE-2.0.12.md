# 墓碑模组 2.0.12 · 开墓后消耗钥匙

原作 **Effect99**。汉化与二改 **lanshiyi**，联系 **3199912548@qq.com**。

## 修改内容

- 手持对应编号的普通绑定钥匙使用墓碑，全部领取遗物成功后消耗本次使用的1把钥匙。
- 背包满或只领取部分遗物时，保留钥匙和剩余遗物，腾出空间继续领取，最后领完才消耗；经验只结算一次。
- 错误钥匙、库存加载失败或缺失、加载期间切换钥匙均不提前消耗。
- 空墓碑成功完成也消耗钥匙；传送次数用尽仍可开墓并消耗。仅传送不会消耗钥匙物品。
- 只消耗实际使用槽位的钥匙，其他墓碑钥匙和未使用副本保留；管理员钥匙不消耗，管理员权限开启不误删无关物品。
- 钥匙属性说明和基本信息同步提示消耗规则。

## 升级

先备份世界，再导入`Gravestones-lanshiyi-v2.0.12.mcaddon`，确认行为包和资源包均启用2.0.12。包UUID、墓碑编号和绑定方式不变，旧版已有钥匙直接适用，无需重新生成。

保持稳定Script API 2.0.0，无需Beta API；最低目标引擎1.21.90。2.0.11的库存实体保护、附近安全传送和落脚台方案继续保留。旧版已经丢失的库存仍需要出问题之前的世界备份恢复。

本版仍为合并行为包和资源包的一个安装包，构建不删除旧包、校验文件或其他已有资料。相关测试记录见`TESTING.md`；未上传仓库或执行线上发布。
